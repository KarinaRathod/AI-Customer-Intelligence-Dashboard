AI-Customer-Intelligence-Dashboard 🎯

An interactive AI-powered customer analytics dashboard built using Streamlit, Plotly, and Scikit-learn.
This application helps businesses analyze customer behavior, identify spending patterns, perform customer segmentation, and predict customer lifetime value using machine learning techniques.

📌 Features
📊 Interactive Dashboard
Real-time KPI metrics
Income vs Spending visualization
Spending category analysis
Dynamic filters for age and income
🧪 Customer Segmentation
AI-powered customer clustering using K-Means
Interactive 3D visualization of customer personas
Segment-wise behavioral analysis
🔮 Predictive Analytics
Customer Lifetime Value (CLV) prediction
Linear Regression-based spending trend forecasting
💬 AI Business Assistant
Query customer insights using simple natural language
Retrieve top earners and spending statistics instantly
📩 Export Reports
Download filtered intelligence reports in CSV format
